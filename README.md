# Good Vibes Restaurant Web Application

A responsive restaurant ordering system built using HTML, CSS, and JavaScript.

## About The Project

The **Good Vibes Restaurant Web Application** was created to showcase my frontend development skills, problem-solving ability, and understanding of modern web design principles.

The website was built with a strong emphasis on:

- Clean and maintainable code
- Responsive design
- Modern UI/UX principles
- User-friendly interactions

## Features

- Responsive design
- Dynamic menu rendering
- Shopping cart functionality
- Local storage integration
- WhatsApp ordering system
- Contact form integration
- Dark/light theme switching

## Technologies

- HTML5
- CSS3
- JavaScript ES6 Modules
