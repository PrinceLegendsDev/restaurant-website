# 🍽️ Good Vibes Restaurant Web Application

A modern, responsive restaurant web application built to help restaurants showcase their menu, provide customers with an interactive ordering experience, and improve customer engagement through online ordering.

## 🌐 Live Demo

🔗 https://good-vibes-restaurant.netlify.app


---

## 📌 Project Overview

Good Vibes Restaurant is a mobile-first website designed for restaurants that want a professional online presence.

The application allows customers to explore available meals, add items to a shopping cart, manage their orders, and place orders through WhatsApp.

---

## ✨ Features

### 🏠 Responsive Restaurant Website
- Modern restaurant landing page
- Mobile-first responsive design
- Optimized layouts for different screen sizes

### 🍔 Dynamic Menu System
- Menu items generated dynamically using JavaScript
- Food cards with images, descriptions, and prices
- Easy menu updates through data changes

### 🛒 Shopping Cart System
- Add and remove items
- Increase/decrease quantities
- Automatic total price calculation
- Cart persistence using local storage
- Real-time cart item counter updates

### 📱 WhatsApp Ordering Integration
- Customers can send orders directly through WhatsApp
- Pre-filled order messages for easier communication

### 🌙 Theme Switching
- Light and dark mode support
- User preference saved using local storage

### 📩 Contact Form
- Customer inquiry form
- Integrated submission workflow
